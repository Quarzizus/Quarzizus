## Proyectos personales

### Emancipar
Aplicación web de gestión de presupuestos personales que permite registrar gastos de forma rápida y natural mediante reconocimiento de voz, usando inteligencia artificial para interpretar el monto, la descripción y el presupuesto correspondiente.

**Tecnologías:** React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Firebase

→ [emancipar.netlify.app](https://emancipar.netlify.app)

### Quarzizus Time
Metrónomo web moderno y progresivo (PWA) con motor de audio de alta precisión basado en Web Audio API y scheduling anticipado para garantizar un ritmo estable. Incluye BPM ajustable de 20 a 240, control de compases, subdivisiones rítmicas, Tap Tempo y un Gap Trainer para entrenar el tiempo interno, todo en una interfaz limpia, responsive e instalable.

**Tecnologías:** React 19 · TypeScript · Vite · Tailwind CSS

→ [quarzizus-time.netlify.app](https://quarzizus-time.netlify.app)
